## 🌟 Overview

**PharmaUniversal** is a high-performance, fully dynamic pharmacy web application designed for a premium user experience. Built with a modern full-stack architecture, it features a real-time database-driven catalog, sophisticated navigation megamenus, and a responsive design tailored for the pharmaceutical industry.

### ✨ Key Features
- 🚀 **Dynamic Inventory**: All products, categories, and site configurations managed via MongoDB.
- 🎨 **Premium UI/UX**: Crafted with Tailwind CSS v4 and Framer Motion for buttery-smooth animations.
- 📱 **Fully Responsive**: Seamless experience across mobile, tablet, and desktop.
- 🔍 **SEO Optimized**: Dynamic metadata and structured semantic HTML for better search rankings.
- 💬 **Interactive Support**: Integrated WhatsApp and floating support chat for real-time customer engagement.

---

## 🛠️ Tech Stack

### Frontend
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 (Custom Design System)
- **Animations**: Framer Motion
- **Icons**: Lucide React + FontAwesome
- **Routing**: React Router DOM

### Backend
- **Server**: Node.js + Express
- **Database**: MongoDB (via Mongoose)
- **API**: RESTful architecture with automated seeding logic

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB (Local or Atlas)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/PharmaUniversal.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables:
   Create a `.env` file in the root directory:
   ```env
   MONGODB_URI=your_mongodb_connection_string
   PORT=5000
   VITE_API_URL=http://localhost:5000/api
   ```
4. Run the development server:
   ```bash
   npm run server
   ```
   *This will concurrently start both the Vite frontend and the Node.js backend.*
